Add the `Organization` content type, representing any organization in the Plone ecosystem: a Plone user, a solution provider, or both. Provider fields move to a `provider_info` behavior, a `facets` index records which roles an organization plays, and the providers vocabulary lists the organizations flagged as such. The REST API representation of an organization gains a `case_studies` key with the case studies it provided and the ones it is the subject of. @ericof
